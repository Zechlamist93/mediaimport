# 💿 MediaImport

An automated Python tool designed to scan, filter, and extract all photo and video files from CDs/DVDs or removable drives into a target folder on your local hard drive — regardless of the source directory structure.

Ein einfaches und effizientes Skript zur automatischen Archivierung von Fotos und Videos von optischen Datenträgern (CD/DVD) auf die Festplatte.

---

## 🌟 Key Features

- **Recursive Media Scanning:** Scans the entire optical drive (including all nested subfolders) for media files.
- **Selective File Filtering:** Automatically detects common image and video formats (JPEG, PNG, RAW, MP4, MOV, AVI, etc.).
- **Flattened Destination Transfer:** Consolidates all found media into a single target directory on your hard drive without losing files.
- **Duplicate Protection / Safe Copy:** Preserves original files while organizing your media collection.
- **Lightweight & Fast:** Pure Python implementation with minimal dependencies.
